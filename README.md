# Project name
  FitLog
## Description

FitLog is a simple workout website where users can find workouts, create a workout plan, save workouts, and track their progress.

### Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- Context API
- REST API

#### Key Features

1. Workout Library
   Users can browse different workouts and see their basic information.

2. Workout Details
   Users can see workout details, instructions, sets, reps, duration, and calories.

3. My Plan
   Users can add workouts to their daily plan and mark them as completed.

4. Save Workouts
   Users can save workouts and view them later.

5. Simple Design & Calculate
   The website has a simple and clean design. Users can also see workout duration and calories burned to help calculate and track their workout progress.
